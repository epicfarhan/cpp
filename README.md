# 🚀 C++ Learning Journey

Welcome to my personal roadmap and code repository for mastering **C++**. This repository documents my progression from the fundamentals to advanced systems programming and modern C++ features.

---

## 🗺️ Learning Roadmap

The learning path is structured into distinct phases to build a solid foundation before moving on to advanced paradigms:

### Phase 1: Foundations & Basics
*   **Variables, Data Types, and Operators**: Understanding memory sizes and basic arithmetic.
*   **Control Flow**: Conditional statements (`if`, `switch`) and loops (`for`, `while`, `do-while`).
*   **Functions**: Scope, parameters, pass-by-value vs. pass-by-reference, and function overloading.
*   **Arrays and Strings**: C-style arrays, `std::string`, and basic manipulation.

### Phase 2: Memory Management & Pointers
*   **Pointers and References**: Memory addresses, dereferencing, and pointer arithmetic.
*   **Dynamic Memory Allocation**: `new`, `delete`, `new[]`, and `delete[]`.
*   **The Rule of Three/Five/Zero**: Destructors, copy constructors, copy assignment operators, move semantics.
*   **Smart Pointers**: `std::unique_ptr`, `std::shared_ptr`, and `std::weak_ptr`.

### Phase 3: Object-Oriented Programming (OOP)
*   **Classes and Objects**: Encapsulation, constructors, destructors, and access modifiers (`public`, `private`, `protected`).
*   **The Four Pillars of OOP**:
    *   Encapsulation
    *   Inheritance (Single, Multiple, Virtual inheritance)
    *   Polymorphism (Compile-time via overloading/templates, Runtime via virtual functions)
    *   Abstraction (Abstract classes and pure virtual functions)

### Phase 4: Standard Template Library (STL)
*   **Containers**: `std::vector`, `std::list`, `std::map`, `std::unordered_map`, `std::set`, `std::stack`, `std::queue`.
*   **Iterators**: Traversing containers safely.
*   **Algorithms**: Sorting, searching, and manipulating data (`std::sort`, `std::find`, `std::for_each`).
*   **Functors and Lambdas**: Anonymous functions and custom sorting logic.

### Phase 5: Advanced C++ & Modern Features
*   **Templates**: Function templates, class templates, and template specialization.
*   **Exception Handling**: `try`, `catch`, `throw`, and custom exceptions.
*   **Modern C++ (C++11/14/17/20)**:
    *   `auto` keyword and type deduction
    *   Move semantics and rvalue references (`&&`)
    *   Structured bindings
    *   Concepts and Coroutines (C++20)
